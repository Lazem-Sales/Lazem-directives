# التوجيهات التشغيلية | لازم

تطبيق صفحة واحدة لإعداد التوجيهات التشغيلية ونسخها إلى محادثة الفريق على Microsoft Teams.

## النشر على GitHub Pages
1. ارفع محتوى هذا المجلد كما هو إلى المستودع، بحيث يكون `index.html` في الجذر مباشرة (ليس داخل مجلد).
2. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` و `/ (root)` ← Save.
3. بعد دقيقة يعمل الرابط: `https://اسم-الحساب.github.io/اسم-المستودع/`

لا تحتاج أي خطوة بناء. مجلد `source` للتعديل لاحقاً فقط (التفاصيل داخله).
