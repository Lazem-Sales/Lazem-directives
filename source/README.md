# الكود المصدري — التوجيهات التشغيلية | لازم

هذا المجلد للتعديل على التطبيق فقط. الموقع نفسه هو ملف `index.html` الموجود في جذر المستودع.

## بعد أي تعديل
```bash
cd source
npm install
npm run release
```
الأمر يبني التطبيق ويضع ملف `index.html` الجديد في جذر المستودع مباشرة. ارفع التغيير إلى GitHub وسيتحدّث الرابط خلال دقيقة.

## أين تعدّل ماذا
- `src/schema.ts` — الأنواع الأربعة وحقولها وما هو إلزامي.
- `src/lib.ts` — صياغة نص التوجيه والتحقق والسجل.
- `src/cities.ts` — قائمة المدن.
- `src/MapField.tsx` — خانة الخريطة والبحث.
- `src/App.tsx` — الواجهة.
